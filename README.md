# Этапы и сроки на доме Алексино

Прототип блока «Этапы и сроки» для сайта ФСП АРТ: выставочный дом в Алексино собирается по пяти этапам до тёплого контура, с 00 до 26 недели, за прокрутку страницы.

Открыть: https://makschakof.github.io/fspanel-etapy/

Прокручивайте страницу колесом. Стрелка в правом нижнем углу окна с домом пропускает анимацию: дом сразу собирается до фасада.

Рабочая версия и история правок лежат в репозитории сайта, `prototypes/etapy-alexino/`. Здесь только копия для показа.
